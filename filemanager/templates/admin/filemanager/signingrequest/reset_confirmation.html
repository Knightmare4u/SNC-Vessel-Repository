Resetting puts each file back the way it was before it was sent for signing:

  • If the signed PDF replaced the original file, the original file is restored.
  • The signing request, its signers, signatures and signing history are deleted.
  • The file is unlocked and can be renamed, deleted or sent for signing again.

If a file was changed after signing, it is left as it is; only the signing request is deleted.
